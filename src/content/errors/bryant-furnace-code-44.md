## What this code means

Bryant Code 44 is a **Blower Calibration Fault**. On variable-speed (ECM) furnace boards, the control runs a calibration routine that measures how the blower motor responds against expected airflow and RPM ranges. When the motor runs **outside that expected range** during calibration, the board flags Code 44.

This is **not** a gas-valve, ignition, or flame-proving code. It points specifically at the variable-speed blower system: the motor, its control/power module, the wiring between the module and board, or airflow restrictions that throw the calibration off.

**Legends vary by board.** On some Bryant board revisions Code 44 has a slightly different definition, so always confirm against the fault legend printed inside your furnace's blower-door panel. Whether the code auto-resets or holds until power is cycled also varies by board — many variable-speed boards will re-attempt calibration on the next call, but a repeated fault typically holds until the underlying issue is fixed.

## Common causes, ranked by probability

1. **Airflow restriction during calibration** — a clogged filter, closed/blocked registers, or a badly restrictive duct system can make the motor's measured airflow fall outside the expected band.
2. **Failing variable-speed blower motor (ECM)** — worn bearings, weak windings, or an internal fault so the motor can't hit or hold the RPMs the board commands.
3. **Faulty blower control/power module** — the module bolted to the motor that drives it can fail or lose calibration data.
4. **Wiring or connector problems** — loose, corroded, or chafed connections between the board, the motor, and the motor module.
5. **Incorrect blower or airflow setup after a service** — wrong CFM/dip-switch or Evolution-control airflow settings entered during a prior install or repair.
6. **Control board fault** — less common, but a bad board can misread motor feedback and trigger the code.

## Safe checks before you call anyone

Stick to these homeowner-safe steps only:

- **Check the air filter.** A dirty or heavily restrictive filter is the most common airflow culprit — replace it if it's dirty.
- **Open all supply and return registers.** Make sure furniture, rugs, or closed vents aren't choking airflow. Confirm the return grille is clear.
- **Confirm the thermostat** is set to Heat with a temperature above room temperature; replace thermostat batteries if it uses them.
- **Check the breaker and the furnace switch.** Make sure the furnace's power switch (looks like a light switch nearby) is on and the breaker isn't tripped.
- **One reset only.** After the above, you may cycle power at the breaker **once** to let the board re-attempt calibration. If Code 44 comes back, stop — do not keep resetting.

Do **not** open the blower compartment, touch wiring, test the motor, or handle the motor module. That's technician work.

## How a technician will diagnose it

A qualified tech will typically:

- Read stored fault history and confirm the exact Code 44 legend for your board revision.
- Verify airflow is not restricted (filter, coil, duct static pressure) before condemning parts.
- Inspect and reseat/measure the wiring and connectors between the board, motor module, and ECM motor.
- Command the blower through its speeds and read RPM/torque feedback to see if the motor responds correctly.
- Test the motor module and motor separately, since either can fail while the other is fine.
- Check the programmed airflow/CFM setup (dip switches or Evolution control) matches the equipment and duct system.
- Confirm the control board reads feedback correctly and force a fresh calibration.

A good quote will name **which** component failed (motor, module, board, or a wiring/setup fix) — not just "replace the blower."

## Symptom, cause and what to do

| Symptom | Likely cause | DIY action | Technician job |
|---|---|---|---|
| Code 44 after filter went unchanged | Airflow restriction | Replace filter, open all vents, one power cycle | Measure static pressure, check duct/coil restriction |
| Blower runs at odd/fixed speed | Failing ECM motor | None | Test motor RPM/torque feedback; replace motor if faulty |
| Code returns right after reset | Motor module fault | One reset only, then stop | Test and replace blower control module |
| Code appeared after a recent service | Wrong airflow/CFM setup | None | Correct dip-switch/Evolution airflow programming |
| Intermittent Code 44, blower sometimes normal | Loose/corroded wiring | Confirm power switch on | Inspect and repair motor/board connectors |
| Multiple faults, erratic behavior | Control board fault | None | Verify feedback readings; replace board if confirmed |

## Repair costs

Honest US ranges (parts + labor; regional and unit variation applies):

- **Filter replacement / airflow fix:** $0–$40 DIY.
- **Airflow setup / re-calibration by tech:** $90–$200 (diagnostic/service call).
- **Wiring or connector repair:** $100–$300.
- **Blower control/power module:** $250–$600 installed.
- **Variable-speed ECM blower motor:** $500–$900 installed.
- **Control board replacement:** $400–$800 installed.

Because a variable-speed motor and its module are expensive, insist the tech confirm which part actually failed before authorizing the repair.
