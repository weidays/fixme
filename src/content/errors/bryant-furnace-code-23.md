## What this code means

Bryant Furnace **Code 23** means **Pressure Switch Did Not Open** — when the furnace began its heating cycle, the control board saw the pressure switch contacts already **closed** *before* the inducer (draft) motor started.

Under normal operation, the pressure switch should be **open** at rest and only close after the inducer starts pulling air. If the board sees it closed at the wrong time, it can't verify that airflow is actually being proven by the inducer — so it flags Code 23 and refuses to fire the burners as a safety measure.

This almost always points to a **stuck-closed pressure switch** or a **shorted / miswired switch circuit**, not to a blockage or weak inducer (that family of problems trips the *opposite* fault — a switch that won't close). Because the fix lives inside the cabinet, this is rated a **pro** repair.

Reset behavior varies by board: many Bryant controls will retry and clear the code once the switch opens normally, but a genuinely stuck switch will keep re-triggering it every cycle. Confirm the exact behavior on your unit's door label.

## Common causes, ranked by probability

1. **Stuck-closed pressure switch** — the diaphragm contacts have failed closed or are gummed up and no longer open at rest. Most common cause.
2. **Shorted or pinched switch wiring** — a wire has chafed against sheet metal or a connector is bridging the two switch terminals, holding the circuit closed.
3. **Miswired switch after a prior repair** — leads reconnected to the wrong terminals or a jumper accidentally left in place.
4. **Condensate or debris in the switch hose** — moisture trapped in the tube can hold the diaphragm closed on some designs.
5. **Failed control board input** — rare, but a board that misreads the switch state can report Code 23 even with a good switch.

## Safe checks before you call anyone

These are the only steps a homeowner should do — nothing inside the cabinet:

- **Cycle the power once.** Turn the furnace switch (or its breaker) off for 30 seconds, then back on to allow one reset attempt. Do **not** repeatedly reset a unit that keeps locking out.
- **Check the thermostat.** Confirm it's set to Heat and the temperature is above room temp; replace batteries if it's a battery model.
- **Inspect the air filter.** A filthy filter won't cause Code 23 on its own, but replace it if it's overdue — clean airflow is always worth ruling out.
- **Look at supply and return vents.** Make sure registers are open and unobstructed.
- **Check the condensate drain.** On high-efficiency models, confirm the condensate line and trap aren't visibly clogged or backed up.
- **Seat the front panels.** Make sure the blower/burner access panels are fully closed so the door switch engages.

If Code 23 returns after one reset, stop and call a technician.

## How a technician will diagnose it

A qualified tech will typically:

1. Read the stored fault history from the control board to confirm Code 23.
2. **Meter the pressure switch** at rest with the inducer off — it should read open. A switch reading closed with no draft is the smoking gun.
3. **Inspect the switch wiring and connectors** for shorts, pinches, corrosion, or a jumper left from a previous repair.
4. Check the **switch hose/tube** for trapped condensate or debris that could hold the diaphragm closed.
5. Verify the board is correctly reading the switch input, and confirm the switch **closes** normally once the inducer runs.
6. Replace the pressure switch or repair the wiring, then run a full heat cycle to confirm the fault clears.

This is a quick diagnosis for an experienced tech — if a quote balloons into replacing the inducer or board before the switch itself is tested, ask why.

## Symptom, cause and what to do

| Symptom | Likely cause | DIY action | Technician job |
|---|---|---|---|
| Code 23 every cycle, no ignition | Stuck-closed pressure switch | Reset power once; verify filter/vents | Meter and replace pressure switch |
| Code 23 after a recent repair | Miswired or jumpered switch | None — call the tech who serviced it | Correct wiring, remove jumper |
| Code 23 intermittent | Chafed or pinched switch wire | Reset once, note when it returns | Inspect/repair switch wiring & connectors |
| Code 23 on high-efficiency unit | Condensate in switch hose | Clear visible condensate drain clog | Clear/replace switch tube, drain trap |
| Code 23 with good switch tested | Faulty board input | None | Replace control board |

## Repair costs

Honest US ranges, parts and labor:

- **Reset only (no parts):** $0 if it clears and stays clear.
- **Diagnostic / service call:** $80–$180 typical.
- **Pressure switch replacement:** $150–$350 installed, depending on model and single- vs two-stage design.
- **Wiring / connector repair:** $100–$250 depending on access and extent.
- **Control board replacement (rare for this code):** $400–$1,200 installed.

Because the pressure switch is inexpensive and the labor is short, most Code 23 repairs land in the **$150–$350** range once diagnosed.
