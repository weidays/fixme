## What this code means

Five flashes on a Trane (or American Standard) furnace control board means **flame was sensed when no flame should be present** — the flame sensor is detecting a signal even though the control has the gas valve commanded off.

This is a safety-critical fault. The furnace control constantly watches the flame-sensing circuit. If it sees a flame signal during a period when the gas valve is supposed to be closed, it assumes either the valve is leaking gas and burning, or the sensing circuit is falsely reporting flame. In both cases the board refuses to operate normally and flashes the code so a technician can investigate.

Because the code involves the gas valve and the flame-proving circuit, **this is professional-level work.** Nothing behind this code is a homeowner repair.

On most Trane integrated furnace controls the fault holds until the condition clears and power is cycled. Exact reset behavior and the flash legend vary slightly by board revision, so confirm the meaning against the diagnostic label printed inside your blower compartment door.

## Common causes, ranked by probability

1. **Gas valve leaking through when commanded off** — the most serious cause. A worn or failed valve passes a small amount of gas that keeps a residual flame, which the sensor correctly detects. This requires valve replacement.
2. **Slow-closing or sticking gas valve** — the valve closes too slowly at the end of a cycle, so flame is still present when the board expects it to be out. Also a valve issue.
3. **Flame sensor or wiring fault giving a false signal** — a shorted flame-sense wire, a grounded sensor rod, or moisture/contamination can make the board "see" flame that isn't there.
4. **Failed or misreading control board** — the flame-sensing input on the integrated furnace control can fail and report flame current when none exists.
5. **Residual flame from hot surface / burner carryover** — in rare cases a lingering flame after shutdown is detected before it fully extinguishes.

Trane's troubleshooting order for this code prioritizes checking the gas valve and flame-proving circuit first, then the control. Because the code varies by board, a technician will always verify against your unit's legend.

## Safe checks before you call anyone

There is very little a homeowner should do here — the underlying causes are all inside the cabinet. Limit yourself to these safe steps:

- **Confirm the thermostat is set correctly** (Heat mode, setpoint above room temperature). This rules out a stray call for heat confusing the sequence.
- **Check and replace a dirty air filter** if it's overdue. A clogged filter won't cause this code but keeps the system healthy for the tech's visit.
- **Verify the furnace switch and breaker.** You may do **one** power cycle: turn the furnace switch off, wait 30 seconds, and turn it back on to see if the code clears.
- **If it returns, stop.** Do not keep resetting a furnace throwing a gas-valve fault. Leave it off and call a technician.
- **If you ever smell gas,** leave the home immediately, don't touch switches, and call your gas utility's emergency line or 911 from outside.

Do **not** open the burner compartment, touch the gas valve, or attempt to clean the flame sensor yourself. That is technician work.

## How a technician will diagnose it

A qualified tech will typically:

1. Pull the diagnostic history from the board and confirm the 5-flash legend against the unit's label.
2. Watch a full heat cycle, then use a **microammeter** to measure flame current during the off period — real leakage shows a sustained flame signal after the valve is commanded closed.
3. **Leak-test the gas valve** and verify it fully closes and seats. A valve passing gas when de-energized is condemned and replaced.
4. Inspect the **flame sensor rod, its ceramic insulator, and wiring** for shorts to ground, contamination, or moisture that could produce a false flame signal.
5. Check the **control board's flame-sense input** and grounding; substitute or replace the board if the valve and sensor test good.
6. Confirm proper burner shutdown timing and correct manifold operation.

A trustworthy quote will name which component tested faulty — valve, sensor, or board — not just "replace everything."

## Symptom, cause and what to do

| Symptom | Likely cause | DIY action | Technician job |
|---|---|---|---|
| 5 flashes, faint flame or heat after shutdown | Gas valve leaking through | Shut furnace off, call a pro | Leak-test and replace gas valve |
| 5 flashes, valve seems to close slowly | Sticking / slow-closing valve | Shut off, do not run | Test valve close timing, replace valve |
| 5 flashes but no flame ever visible | False flame signal from sensor/wiring | One reset, then call if it returns | Inspect and repair/replace flame sensor and wiring |
| Code persists after valve and sensor test good | Control board flame-sense fault | None | Replace integrated furnace control |
| Code appears once, clears, doesn't return | Momentary flame carryover | One reset, monitor | Verify no recurring fault on next visit |

## Repair costs

Ranges are typical US installed prices; your area, model, and parts availability will move them.

- **Diagnostic / service call:** $90 – $180
- **One power reset (no parts):** $0 if it clears and doesn't return
- **Flame sensor replacement:** $150 – $300 (part is cheap; labor and access drive cost — technician work on this board)
- **Gas valve replacement:** $300 – $600 depending on valve type and furnace model
- **Integrated furnace control board:** $400 – $700 installed
- **After-hours / emergency premium:** add $100 – $250

A recurring 5-flash code most often ends in a **gas valve** or **control board** replacement, so budget toward the middle-to-upper end if a single reset doesn't hold.
