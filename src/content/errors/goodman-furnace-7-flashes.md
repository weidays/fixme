## What this code means

Seven flashes on your Goodman furnace control board means **low flame signal** — the flame sensor is detecting a flame, but the signal is too weak for the board to consider it reliable.

Your furnace proves flame by measuring a tiny electrical current (flame rectification) through a metal rod that sits in the burner flame. When that current drops below the board's threshold, the control logs a 7-flash code. This is different from *no* flame being sensed — here, the flame is present but the signal is marginal.

A weak signal is usually caused by a dirty or oxidized flame sensor, a poor electrical ground, or a flame that isn't fully covering the sensor rod. If the signal keeps dropping, the furnace typically progresses to an **ignition lockout**. The flash pattern used to indicate that lockout differs by control board and board revision, so read the lockout code off the diagnostic legend inside your blower door rather than assuming a number. Either way, treat 7 flashes as an early warning.

Reset behavior varies by board too: most Goodman controls keep attempting to run and will operate whenever the signal recovers, but a chronically weak signal ends in lockout. Confirm the exact behavior on the diagnostic label inside your blower compartment.

## Common causes, ranked by probability

1. **Dirty or oxidized flame sensor** — By far the most common cause. A film of carbon or oxidation on the sensor rod insulates it and drops the microamp signal. This builds up gradually over a season or two.
2. **Poor or loose ground connection** — Flame rectification depends on a solid ground path (furnace chassis, burner assembly, and to earth). A corroded or loose ground causes an artificially low reading.
3. **Flame not fully covering the sensor rod** — Partially clogged burner ports, incorrect gas pressure, or a slightly misaligned/bent sensor can leave the rod only partly in the flame.
4. **Corroded or loose flame-sensor wire/connector** — High resistance in the sensor lead reduces the signal reaching the board.
5. **Weak or failing control board** — Less common; the board's flame-sensing circuit itself can degrade and misread an otherwise healthy flame.

## Safe checks before you call anyone

These are the only steps a homeowner should perform. Everything involving the sensor, burners, or wiring is technician work.

- **Air filter** — A clogged filter can disturb airflow and combustion. Replace a dirty filter with the correct size.
- **Thermostat** — Confirm it's set to Heat with the setpoint above room temperature. Replace thermostat batteries if it uses them.
- **Breaker / power switch** — If the furnace is locked out, cycle the breaker or the furnace service switch **once** to allow one restart. Do not repeat resets.
- **Supply and return vents** — Make sure registers throughout the house are open and unobstructed.
- **Condensate line (high-efficiency models)** — Check that the drain isn't overflowing or blocked; a backup can cause other faults.

If the 7-flash code returns after one reset, stop and call a technician — the sensor and ground checks require opening the cabinet.

## How a technician will diagnose it

A qualified tech will:

1. Read the stored flash code and confirm it against the board legend.
2. Put a meter in series with the flame sensor and **measure the flame-rectification current in microamps** during a heating cycle, comparing the reading to the minimum printed in your unit's service literature rather than to a universal figure.
3. Remove and **inspect/clean the flame sensor** with fine abrasive if it's coated.
4. **Verify the ground path** — checking the burner assembly, chassis ground, and the ground back to the board.
5. Inspect burners for partial clogging and check that flame fully engulfs the sensor rod.
6. Test the sensor lead/connector for resistance or damage.
7. Recheck the microamp reading after cleaning and, if it's still low with a good sensor and ground, evaluate the control board.

If a tech quotes a full board replacement without first measuring the flame current and cleaning the sensor, ask why — the sensor is a far more common and cheaper culprit.

## Symptom, cause and what to do

| Symptom | Likely cause | DIY action | Technician job |
|---|---|---|---|
| 7 flashes, furnace runs then drops out | Dirty flame sensor | Reset once; replace filter | Clean or replace flame sensor, remeasure microamps |
| Intermittent heat, code returns | Poor ground connection | None safe inside cabinet | Test and repair ground path |
| Flame lights but signal weak | Flame not covering sensor rod | None safe inside cabinet | Inspect burners, correct gas pressure, realign sensor |
| Code comes back soon after a technician cleaned the sensor | Bad sensor lead/connector | None safe inside cabinet | Repair or replace sensor wiring |
| Persists after clean sensor + good ground | Failing control board | None | Test and replace integrated control board |
| Progresses to an ignition lockout (code per your board legend) | Signal fell below threshold | Reset once only | Full flame-sense diagnosis |

## Repair costs

Honest US ranges, parts and labor combined:

- **Flame sensor cleaning** — $80–$180 as part of a service visit. Often resolves the code entirely.
- **Flame sensor replacement** — $100–$250. The part itself is inexpensive ($10–$30); most of the cost is the trip and labor.
- **Ground connection repair** — $100–$250, depending on where the fault is and how much rework is needed.
- **Burner cleaning / adjustment** — $150–$350 if ports are clogged and burners must be pulled.
- **Flame-sensor wiring/connector repair** — $100–$250.
- **Control board replacement** — $400–$1,200 including labor; only warranted after the sensor and ground are ruled out.

Many 7-flash calls are resolved with a straightforward sensor cleaning, so the low end of that range is the common outcome — but budget for the higher figures if burners must be pulled or the integrated control is condemned.
